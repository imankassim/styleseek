# evaluation/results/

Saved per-query ranked result lists (architecture §18 minimum artefact set) — generated by
`python evaluation/save_results.py`. Dated snapshots of the current index/model state (see that
script's docstring for why these aren't literal reconstructions of historical `experiments/EXPnn`
runs), not a moving target that gets silently overwritten — each run adds a new dated file rather
than replacing the previous one.
